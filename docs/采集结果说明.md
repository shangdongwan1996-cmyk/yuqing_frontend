# 采集结果字段说明

> 所有采集结果统一输出格式，按字段对照表说明。

---

## 一、顶层字段

| 中文名 | 字段名 | 类型 | 必填 | 说明 |
|--------|--------|------|------|------|
| Schema版本 | schema | string | 是 | 固定为 `yuqing.v1` |
| 流水号 | serialNo | string | 是 | 每次采集任务唯一标识，如 `TASK-20260517-001` |
| 平台 | platform | string | 是 | 枚举: `douyin` / `taobao_live` / `news` / `weibo` |
| 关键词 | keyword | string | 是 | 本次搜索使用的关键词 |
| 关键词分组 | keywordGroup | string | 否 | 关键词库中的分组名称 |
| 爬取级别 | crawlLevel | string | 是 | `L1` / `L2` / `L3` / `L4` |
| 采集时间 | collectedAt | string | 是 | ISO 8601 格式，如 `2026-05-17T10:30:00.000Z` |
| 结果总数 | totalResults | number | 是 | 本批次返回的结果数量 |

---

## 二、内容列表

`contents` 为数组，每条包含以下字段：

### 2.1 基础信息

| 中文名 | 字段名 | 类型 | 必填 | 说明 |
|--------|--------|------|------|------|
| 内容流水号 | contentId | string | 是 | 全局唯一，格式 `{platform}_{nativeId}` |
| 内容类型 | contentType | string | 是 | `video`(短视频) / `live_stream`(直播) / `article`(文章) / `hot_search`(热搜) |
| 平台原始ID | nativeId | string | 是 | 平台侧的唯一ID |
| 标题 | title | string | 否 | 视频文案/直播间标题/文章标题，最长200字 |
| 封面图 | coverUrl | string | 否 | 封面图URL |
| 原文链接 | url | string | 是 | 内容的原始链接 |

### 2.2 作者信息

| 中文名 | 字段名 | 类型 | 必填 | 说明 |
|--------|--------|------|------|------|
| 作者ID | authorId | string | 是 | 作者全局唯一ID |
| 作者昵称 | nickname | string | 是 | 作者名称/昵称 |
| 粉丝数 | followerCount | number | 否 | 作者粉丝数，部分平台可能缺失 |

### 2.3 指标数据

| 中文名 | 字段名 | 类型 | 必填 | 说明 |
|--------|--------|------|------|------|
| 播放量/观看数 | viewCount | number | 是 | 抖音为播放次数，淘宝直播为观看人数 |
| 点赞数 | likeCount | number | 否 | 新闻/热搜等平台无此数据时返回 0 |
| 评论数 | commentCount | number | 否 | — |
| 分享数/转发数 | shareCount | number | 否 | — |

### 2.4 时间信息

| 中文名 | 字段名 | 类型 | 必填 | 说明 |
|--------|--------|------|------|------|
| 发布时间 | publishedAt | string | 否 | 视频发布时间/直播开始时间/文章发布时间 |
| 采集时间 | collectedAt | string | 是 | 本条数据采集时刻 |

### 2.5 平台扩展

| 中文名 | 字段名 | 类型 | 必填 | 说明 |
|--------|--------|------|------|------|
| 平台扩展字段 | platformFields | object | 否 | 各平台特有数据，见下方对照表 |

---

## 三、平台扩展字段对照

### 抖音

| 中文名 | 字段名 | 说明 |
|--------|--------|------|
| 视频时长(秒) | videoDuration | number，如 120 |

### 淘宝直播

| 中文名 | 字段名 | 说明 |
|--------|--------|------|
| 直播状态 | liveStatus | `living`(直播中) / `replay`(回放) |
| 商品数量 | productCount | number，直播间当前商品数 |
| 商品价格 | prices | string[]，如 `["¥29.9", "¥59.9"]` |

### 微博热搜

| 中文名 | 字段名 | 说明 |
|--------|--------|------|
| 排名 | rank | number，如 1 |
| 排名变化 | rankChange | string，如 `up_3` / `down_2` / `new` |
| 热度等级 | hotLevel | string，如 `爆` / `热` / `新` |

---

## 四、统计摘要

| 中文名 | 字段名 | 类型 | 说明 |
|--------|--------|------|------|
| 结果总数 | totalResults | number | 本次返回条数 |
| 去重作者数 | totalAuthors | number | 涉及的不同作者数量 |
| 作者列表 | authors | string[] | 所有作者昵称 |
| 平均播放量 | avgViewCount | number | — |
| 平均点赞数 | avgLikeCount | number | — |
| 平均评论数 | avgCommentCount | number | — |

## 六、平台字段映射（原始→标准）

### 抖音

```
statistics.play_count     → viewCount
statistics.digg_count     → likeCount  
statistics.comment_count  → commentCount
statistics.share_count    → shareCount
author.nickname           → nickname
author.sec_uid            → authorId
create_time               → publishedAt
desc                      → title
```

### 淘宝直播

```
[class*="infoText"] 含"观看"  → viewCount
[class*="accountName"]        → nickname
[class*="livingIcon"] 是否存在 → platformFields.liveStatus
[class*="price"] 列表         → platformFields.prices
```

## 七、取值规则

| 规则 | 说明 |
|------|------|
| 缺失数值 | 统一返回 0 |
| 缺失文本 | 统一返回空字符串 `""` |
| 缺失对象 | 统一返回 `null` |
| 内容去重 | 按 `contentId` 去重，保留最新 |
| 单次上限 | 最多 50 条 |
| 标题长度 | 不超过 200 字 |
